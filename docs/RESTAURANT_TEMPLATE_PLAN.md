# Restaurant & Sushi Restaurant Templates - Complete Plan

## Executive Summary

This document outlines the complete feature set and design specifications for restaurant and sushi restaurant website templates for ParaguAI Builder. Based on research of successful sushi restaurants including Kaitensu Sushi en Movimiento, Kaiten Zushi NYC, and industry best practices.

## 📱 Core Sections (All Restaurant Types)

### 1. Hero Section
**Purpose:** First impression, key messaging, primary CTAs

**Content:**
- Restaurant name and tagline
- High-quality hero image (food, interior, or chef)
- Primary CTA buttons:
  - "Reservar Mesa" / "Book a Table"
  - "Ver Menú" / "View Menu"
  - "Ordenar Online" / "Order Online" (if applicable)
- Brief description/unique selling proposition
- Business hours badge ("Abierto Ahora" / "Open Now")

**Design Elements:**
- Full-width background image with overlay
- Typography: Bold restaurant name, elegant tagline
- Color: Brand primary color for CTAs
- Mobile: Stacked layout, swipeable image gallery

---

### 2. About / Story Section
**Purpose:** Build trust, share restaurant philosophy

**Content:**
- Restaurant history/founding story
- Chef/owner biography with photo
- Philosophy/mission statement
- Awards/certifications
- Local sourcing stories
- Team photos

**Sushi-Specific Additions:**
- Chef's training background (Japan, apprenticeships)
- Fresh fish sourcing (Toyosu Market, daily delivery)
- Traditional preparation methods
- "Mutan" philosophy (nothing added, pure ingredients)
- Years of experience

---

### 3. Menu Section
**Purpose:** Display food offerings with prices

**Content:**
- Categorized menu items:
  - **Appetizers / Entradas**
  - **Main Courses / Platos Principales**
  - **Sides / Acompañamientos**
  - **Desserts / Postres**
  - **Beverages / Bebidas**
- Each item includes:
  - Name (English + Local language)
  - Description
  - Price
  - Dietary tags (V = Vegetarian, VG = Vegan, GF = Gluten-Free, SP = Spicy)
  - Photo (optional)

**Sushi-Specific Categories:**
- **Sashimi** - Fresh fish slices
- **Nigiri** - Fish over rice
- **Maki** - Rolled sushi
- **Specialty Rolls** - Signature creations
- **Hand Rolls (Temaki)** - Cone-shaped
- **Appetizers** - Edamame, miso soup, gyoza
- **Hibachi / Teppanyaki** - Grilled dishes
- **Omakase** - Chef's selection courses
- **Sake & Drinks** - Japanese beverages

**Design Elements:**
- Tabbed interface for categories
- Accordion for sub-categories
- Price alignment (right-aligned)
- Dietary indicator badges
- High-quality food photography
- Printable PDF download option

---

### 4. Online Ordering Section
**Purpose:** Enable direct food ordering

**Content:**
- Ordering options:
  - Pickup / Para Llevar
  - Delivery / Delivery
  - Dine-in (pre-order)
- Menu items with add-to-cart functionality
- Special instructions field
- Order scheduling (now/later)
- Payment integration (MercadoPago, etc.)

**Design Elements:**
- Card-based menu items
- Quantity selectors
- Cart sidebar/drawer
- Checkout flow
- Order confirmation

**Third-Party Integrations:**
- UberEats button/link
- PedidosYa
- Rappi
- DoorDash (if available)

---

### 5. Reservations Section
**Purpose:** Table booking system

**Content:**
- Reservation form:
  - Date picker
  - Time slots (based on availability)
  - Party size
  - Name and contact info
  - Special requests (allergies, celebrations)
- Available time slots display
- Table preference (indoor/outdoor/bar)

**Sushi-Specific Additions:**
- Omakase reservations (timed seatings: 5PM, 7PM, 9PM)
- Chef's counter seating option
- Private dining room booking
- Group event reservations

**Design Elements:**
- Calendar widget
- Time slot buttons
- Party size selector
- Form validation
- Confirmation email

## 🎨 Design Specifications

### Color Schemes

**General Restaurant:**
- **Warm & Inviting:** Earth tones, browns, oranges
- **Modern Minimalist:** Black, white, accent color
- **Rustic:** Wood tones, greens, cream
- **Fine Dining:** Dark backgrounds, gold accents

**Sushi Restaurant:**
- **Traditional Japanese:** Black, red, white, wood
- **Modern Minimalist:** White, charcoal, bamboo green
- **Ocean Fresh:** Blues, whites, teals
- **Premium/Luxury:** Dark backgrounds, gold, deep red

### Typography

**General:**
- Headings: Bold, readable (Playfair Display, Lora)
- Body: Clean sans-serif (Inter, Source Sans)
- Menu items: Clear hierarchy

**Sushi:**
- Japanese-inspired fonts for accents
- Clean, elegant headings
- Traditional + modern balance

### Layout Patterns

**Homepage Structure:**
1. Hero (full-width)
2. About/Story (text + image)
3. Featured Menu Items (3-6 cards)
4. Reservations CTA
5. Photo Gallery (grid)
6. Reviews
7. Location/Hours
8. Footer

**Menu Page:**
- Sticky category navigation
- Two-column layout (desktop)
- Accordion sections (mobile)

**Mobile-First:**
- Hamburger menu
- Sticky CTA buttons (Call, Order, Reserve)
- Swipeable galleries
- Tap-to-call
