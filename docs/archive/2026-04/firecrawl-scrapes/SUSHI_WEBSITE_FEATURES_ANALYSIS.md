## Common Sections Found on Sushi Restaurant Websites

### 1. Hero / Home Section
- Large hero images/videos of sushi
- Restaurant name and tagline
- Key value proposition (e.g., "All-you-can-eat", "Conveyor belt experience")
- Call-to-action buttons (Order Online, View Menu, Make Reservation)

### 2. About / Story Section
- Restaurant history and philosophy
- Chef background and credentials
- "Mutan" philosophy (nothing added, natural flavors)
- Establishment date
- Mission statement

### 3. Menu Section
- Multiple menu types:
  - Sushi Menu
  - Hibachi Menu
  - Kids Menu
  - Desserts
  - Seasonal Menu
  - Bar/Drinks Menu
- Categorized items (Maki Rolls, Nigiri, Sashimi, Hand Rolls)
- Item descriptions with ingredients
- Pricing information
- Dietary indicators (spicy, raw, vegetarian)

### 4. Online Ordering
- Direct ordering integration
- Third-party delivery apps (Uber Eats, DoorDash, Postmates, Grubhub)
- Pickup ordering
- Catering orders
- Shopping cart functionality
- Checkout process
- Order modification
- Time selection for pickup/delivery

### 5. Reservations
