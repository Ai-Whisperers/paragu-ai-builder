# Quick Start Guide: Peluquería & Gimnasio Outreach

> 30-second guide to start converting leads today

## The 3-Step Process

### Step 1: Find a Hot Lead (30 seconds)

1. Go to: `/admin/leads`
2. Filter by **Business Type** = `peluqueria` or `gimnasio`
3. Sort by **Priority Score** (highest first)
4. Click on a **Hot** priority lead

**What to look for:**
- High rating (4+ stars)
- Many reviews (20+)
- No website (`has_website = false`)
- Has WhatsApp number

### Step 2: Send WhatsApp (1 minute)

1. In the lead detail panel (right side), click **WhatsApp** button
2. Message opens in WhatsApp Web or app
3. Send the pre-written message

**The message says:**
> "Hola [Business Name]! Soy de Paragu-AI. Veo que no tienen sitio web aún. Podemos crearles uno profesional para atraer más clientes. ¿Tienen 5 minutos para conversar?"

**What happens automatically:**
- Click is tracked in database
- Lead status changes to "contacted"
- Timestamp recorded

### Step 3: Generate & Send Preview (2 minutes)

**If they respond positively:**

1. In the lead detail panel, click **Generar Preview**
2. Wait for the toast notification (shows preview URL)
3. Copy the URL (looks like: `/s/preview-abc123`)
4. Send via WhatsApp: "¡Su demo está lista! Pueden verla aquí: [URL]"

**What happens:**
- Preview site created in ~5 seconds
- Site includes their business name
- All sections ready (services, team, contact)
- Lead status changes to "demo_ready"

## Pro Tips

### Best Times to Message
- **Salons:** Tuesday-Thursday, 10am-12pm (before rush)
- **Gyms:** Monday-Wednesday, 2pm-4pm (after lunch rush)

### What Makes Leads Convert
1. **Speed** - Generate preview while on the call/chat
2. **Social proof** - Mention other businesses in their area
3. **Low risk** - Emphasize "demo gratuita", "sin compromiso"

### Red Flags (Don't Waste Time)
- No phone/WhatsApp number
- Status already "paying" with another provider
- Explicitly said "no interested" in the past

## Tracking Your Work

### Lead Status Meanings
| Status | Meaning | Action |
|--------|---------|--------|
| `new` | Never contacted | Send WhatsApp |
| `contacted` | WhatsApp sent | Wait for reply |
| `demo_ready` | Preview generated | Follow up on demo |
| `responded` | They replied | Continue conversation |
| `paying` | Converted! | 🎉 |

### Tags to Use
- `interesado` - They want to continue
- `llamada_programada` - Call scheduled
- `demo_vista` - They viewed the demo
- `negociacion` - Discussing pricing
- `seguimiento_necesario` - Need to follow up later
