## ¿Qué necesitan de este sitio?

Marcar todos los que apliquen:

- ☐ Mostrar servicios / productos
- ☐ Recibir consultas por formulario
- ☐ Agendar citas en línea (Calendly / similar)
- ☐ Vender online (catálogo + pago)
- ☐ Galería de trabajos / portafolio
- ☐ Blog / noticias
- ☐ Testimonios de clientes
- ☐ Varios idiomas (especificar): _________________
- ☐ Panel admin para ver leads
- ☐ Boletín / newsletter
- ☐ Otro: _________________
