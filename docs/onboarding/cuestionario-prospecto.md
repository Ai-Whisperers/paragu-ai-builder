- ☐ **LIGHT CUSTOMIZATION (Tier Pro/Premium — Gs 1.2M–2M)**
  - Existe demo cercano pero falta 1–2 secciones específicas
  - O cliente quiere funcionalidad existente pero en otro rubro
  - Cliente tiene contenido parcial (necesitamos redactar algunas secciones)

- ☐ **HEAVY CUSTOMIZATION (Tier Premium — Gs 2M–5M)**
  - Demo existente como base, pero se agregan 3+ secciones nuevas

  - Falta mucho contenido — redactamos nosotros

  - Cliente requiere panel admin personalizado
  - Entrega: **4–12 semanas**
  - Construcción con los section components existentes + componentes nuevos a medida
