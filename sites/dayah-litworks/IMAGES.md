# PART 5: AI PROMPT CHEATSHEET

## Midjourney Parameters Reference

| Parameter | Short | Values | Meaning |
|-----------|-------|--------|---------|
| --aspect | --ar | 16:9, 2:3, 1:1 | Aspect ratio |
| --version | --v | 1-6 | Model version |
| --stylize | --stylize | 0-1000 | Artistic strength |
| --image-weight | --IW | 0-2 | Image prompt strength |
| --no | --no | [subject] | Exclude |
| --quality | --q | 0.5, 1, 2 | Render quality |

## Quick Prompt Templates

### Book Cover (Any Genre)
```
[GENRE] book cover, professional design, [MOOD], [COLOR PALETTE], [SPECIAL ELEMENTS], cinematic lighting, 4k --ar 2:3 --v 6 --stylize 250
```

### Flat Lay
```
minimalist [PRODUCT] flat lay, [BACKGROUND], soft natural lighting, professional photography --ar [RATIO] --v 6 --stylize 200
```

### Social Media
```
[TOPIC] social media post, [STYLE], clean modern design, [COLORS] --ar [RATIO] --v 6 --stylize 200
```
