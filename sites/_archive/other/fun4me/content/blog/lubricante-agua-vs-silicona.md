# Lubricante base agua vs silicona: cuál elegir

El lubricante no es opcional — es el complemento que marca la diferencia entre "incómodo" y "perfecto". Pero hay que elegir el correcto según el uso. Esta es la regla corta:

## Regla rápida

| Situación | Lubricante correcto |
|---|---|
| Con juguete de silicona | **Base agua** (la silicona degrada juguetes de silicona) |
| Con juguete de vidrio / acero / ABS | Cualquiera |
| Con condón de látex | Cualquiera |
| Con condón de poliuretano | Base agua o híbrido |
| En la ducha / piscina | **Base silicona** (agua no funciona) |
| Uso anal | **Base silicona** (más duradero, menos fricción) |
| Piel sensible / tendencia a infecciones | **Base agua** (menos propenso a alergias) |

## Lubricante base agua

**Ventajas:**
- Compatible con todos los materiales (juguetes y condones).
- Fácil de limpiar con agua.
- No mancha telas.
- Apto para sexo vaginal, oral y anal.
- Usualmente libre de alérgenos.

**Desventajas:**
- Se seca con el tiempo (necesitás reaplicar cada 10-15 minutos).
- No funciona bajo agua.
- Algunos contienen glicerina (si tenés tendencia a candidiasis, elegí "glycerin-free").

**Cuándo elegirlo:** sesiones cortas/medianas, con juguetes de silicona, si sos propensa a infecciones.

## Lubricante base silicona

**Ventajas:**
- Larga duración (no se seca en horas).
- Funciona en ducha, piscina, jacuzzi.
- Sensación sedosa, menos pegajoso.
- Ideal para juego anal (menos fricción).

**Desventajas:**
- **NO usar con juguetes de silicona** (degrada la superficie).
- Mancha telas (puede dejar marca en sábanas).
- Más difícil de limpiar (necesitás jabón, no solo agua).
- Más caro.

**Cuándo elegirlo:** sesiones largas, juego anal, ducha, con juguetes de vidrio/metal/ABS.

## Lubricante híbrido

Mezcla de agua y silicona. Intenta lo mejor de ambos: duración intermedia, compatible con más materiales. Algunos juguetes de silicona de alta calidad (LELO, We-Vibe) toleran híbridos, pero **siempre verificá las indicaciones del fabricante**.

## ¿Qué hay de los "saborizados"?

Muchos son base agua con saborizante. Perfectos para sexo oral. Pero verificá que no tengan azúcar (puede causar infecciones vaginales/anales). Marcas recomendadas: System JO, Durex Play, ID.

## Errores comunes

1. **"Uso aceite de cocina / vaselina"** — NO. Daña condones de látex, puede causar infecciones, no está formulado para contacto íntimo.
2. **"Uso saliva"** — No es lubricante. Se seca rápido, contiene bacterias.
3. **"Más lubricante = mejor"** — Exceso puede reducir fricción útil. Una gota del tamaño de una moneda es suficiente para empezar.
