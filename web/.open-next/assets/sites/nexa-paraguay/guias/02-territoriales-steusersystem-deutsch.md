# Territoriales Steuersystem Paraguay
## Der-complete Führer für europäische Investoren und Unternehmer

---

**Version:** 2.0 — April 2026  
**Sprache:** Deutsch  
**Für:** Investoren und Unternehmer aus Nederland, Deutschland, Spanien

---

:::{.callout-tip}
**Zusammenfassung:** Paraguay hat ein **einzigartiges territoriales Steuersystem** — Sie besteuern nur Einkünfte, die innerhalb des Landes erzielt werden. Einkünfte aus dem Ausland werden mit **0% besteuert**.
:::

## 1. Das Territoriale System Erklärt

### Das Grundprinzip

```
┌─────────────────────────────────────────────────────────────┐
│         TERRITORIALES STEUERSYSTEM PARAGUAYS                │
├─────────────────────────────────────────────────────────────┤
│                                                     │
│   EINKUNFT QUELLE PARAGUAY ─────► 10% max. (IRE/IRP)     │
│                                                     │
│   EINKUNFT QUELLE AUSLAND ────► 0% (nicht besteuert)      │
│                                                     │
│   Diese Regel gilt für:                                │
│   • Dividenden ausländischer Unternehmen              │
│   • Gehalt für Remote-Arbeit                          │
│   • Beratung für internationale Kunden                │
│   • Erträge aus Investitionen                         │
│   • Kapitalerträge                                   │
└─────────────────────────────────────────────────────────────┘
```

| Aspekt | Paraguay (Territorial) | Deutschland (Weltweit) | Spanien (Weltweit) | Niederlande (Weltweit) |
|:-------|:----------------------:|:--------------------:|:-----------------:|:---------------------:|

## 2. Steuersätze 2026

### Einkommensteuer (IRP)

| Jährliches Einkommen (PYG) | Einkommen (USD) | Satz |
|:--------------------------|:---------------|:----:|
| 0 - 50.000.000 | $0 - 6.350 | **8%** |
| 50.000.001 - 150.000.000 | $6.350 - 19.000 | **9%** |
| Über 150.000.000 | Über $19.000 | **10%** |

### Körperschaftsteuer (IRE)

| Entity-Typ | Satz | Bemessungsgrundlage |
|:-----------|:----:|:-----------------|
| Allgemein (SA, SRL, EAS) | **10%** | Nettogewinn |
| SIMPLE-Regime | 10% (auf 30% brutto) | 3% effektiv |
| Non-Profit-Organisationen | 0% | Variierend |

### Sonstige Steuern

| Steuer | Satz | Auslöser |
|:-------|:---:|:--------|
| IVA (USt) | 10% | Verkäufe/Dienstleistungen |
| IDU (Dividenden) | 8% Gebietsansässige | Ausschüttung |
| IDU (Dividenden) | 15% Nicht-Gebietsansässige | Ausschüttung |
| INR (Nicht-Ansässige) | 4,5-15% | PY-Quelleneinkünfte |

## 3. Praktische Beispiele

### Beispiel 1: Freiberufler mit niederländischem Kunde (Remote)

```
Situation:
├── Einkommen: €5.000/Monat für Beratung NL-Kunde
└── Dienstleistungen von Paraguay aus (remote)

Ergebnis Paraguay:
├── Besteuerung: €0 (ausländische Quelle)
└── Verfügbar: €60.000/Jahr

Vergleich:
├── In Deutschland: ~€17.500 Steuern
├── In Paraguay: €0
└── Ersparnis: €17.500/Jahr
```

### Beispiel 2: Gehalt von paraguayanischem Unternehmen

```
Situation:
├── Gehalt: ₲50.000.000/Jahr (~$6.350)
├── Paraguayanisches Unternehmen
└── Arbeit in Paraguay erbracht

Ergebnis Paraguay:
├── IRP: 8% auf ₲50.000.000
└── Steuer: ₲4.000.000/Jahr (~$500)
```

### Beispiel 3: Dividenden von deutschem Unternehmen

```
Situation:
├── Dividenden von DE-Unternehmen: €30.000/Jahr
└── Paraguayanischer Steuer resident

Ergebnis Paraguay:
├── Besteuerung: €0 (ausländische Quelle)
└── Verfügbar: €30.000 (nicht besteuert in PY)
```

## 5. Steuerlicher Wohnsitz

### Kriterien für steuerlichen Wohnsitz

| Kriterium | Definition |
|:---------|:----------|
| Gewöhnlicher Aufenthalt | Hauptwohnsitz |
| Mittelpunkt der Lebensinteressen | Familie, Geschäft, soziale Bindungen |
| 183 Tage | Körperliche Anwesenheit |

### Aufenthalt vs Immigration

| Migrationsstatus | Steuerliche Implikation |
|:---------------|:-------------------|
| Tourist | Kein Steuer resident — nur PY-Einkommen besteuert |
| Temporärer Aufenthalt | Resident — weltweites Einkommen (territorial) |
| Permanenter Aufenthalt | Resident — weltweites Einkommen (territorial) |

:::{.callout-warning}
**Wichtig:** Paraguay nimmt seit 2017 am CRS (Common Reporting Standard) teil. Bankkonten werden an Ihr Wohnland gemeldet.
:::

## 8. Häufig Gestellte Fragen

### Wie viel Steuer zahle ich für Remote-Arbeit für einen europäischen Kunden?

**0%.** Wenn der Kunde außerhalb Paraguays ist und die Dienstleistungen außerhalb erbracht werden, ist es Auslandsquelle → 0% in Paraguay.

### Muss ich Konten in Paraguay in meinem Heimatland deklarieren?

**Ja.** Paraguay nimmt am CRS teil. Sie müssen das Konto in Ihrer Steuererklärung im Heimatland deklarieren.

### Kann ich IRP vermeiden, wenn ich kein steuerlicher Resident bin?

Als Tourist (<183 Tage) und ohne Aufenthaltsrecht besteuern Sie nur paraguayanische Quelleinkünfte.

### Eliminiert das Abkommen mit Spanien die Doppelbesteuerung?

**Teilweise.** Das Abkommen reduziert Dividendeneinbehalt, eliminiert aber nicht die Besteuerung im Quellland.
